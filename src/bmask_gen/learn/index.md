# 深層学習入門：DeepLabV3+ によるケーブルセグメンテーションを題材に

このワークスペースで実装した `train_deeplabv3plus_binary.py` と `infer_live.py` のコードを読み解きながら、深層学習の基礎を体系的に学ぶ資料です。

---

## 章構成

### 第1章　画像データの表現
- 画像の数値表現（ピクセル、チャンネル、BGR/RGB）
- テンソルとは何か（スカラー・ベクトル・行列・テンソルの関係）
- PyTorch における画像の形式：`(C, H, W)` と `(B, C, H, W)`
- 正規化（0〜255 → 0.0〜1.0）の意味

### 第2章　畳み込みニューラルネットワーク（CNN）
- 全結合層の限界と畳み込み層のアイデア
- 畳み込み演算：カーネル・ストライド・パディング
- プーリング層（空間解像度のダウンサンプリング）
- 活性化関数：ReLU の役割
- CNN の出力が「特徴マップ」になるイメージ

### 第3章　バックボーン
- バックボーンとは何か（特徴抽出器としての CNN）
- タスクヘッドとバックボーンの役割分担
- 有名なバックボーンの紹介（VGG・ResNet・EfficientNet など）
- ResNet の残差接続（Residual Connection）：なぜ深いネットワークに必要か
- 勾配消失問題と残差接続による解決策
- このプロジェクトで ResNet34 をバックボーンとして使っている箇所（コード対応）

### 第4章　セグメンテーションとエンコーダ・デコーダ
- 画像分類・物体検出・セグメンテーションの違い
- バイナリセグメンテーション（ケーブルか背景か）
- エンコーダ：バックボーンが特徴を抽出しながら解像度を落とす
- デコーダ：解像度を元に戻しながらマスクを生成する
- スキップコネクション：細かい位置情報を補う仕組み

### 第5章　損失関数・最適化・学習の制御
- 損失関数の役割（モデルの「間違い」を数値化する）
- バイナリセグメンテーションに `BCEWithLogitsLoss` を使う理由
- シグモイド関数：ロジットを確率に変換する
- 勾配降下法のアイデア
- Adam：学習率を自動調整する最適化アルゴリズム
- バッチサイズとは（なぜデータを小分けにして学習するか）
- エポックとは（データセット全体を何周するか）
- イテレーションとの関係：`エポック × (データ数 ÷ バッチサイズ)`
- loss グラフの読み方：train loss と val loss の推移を見る
- 過学習（Overfitting）とは：訓練データに特化しすぎて未知データに弱くなる現象
- 汎化性能とは：未知データに対してどれだけ正しく予測できるか
- 過学習のサイン：train loss は下がるが val loss が上昇し始める
- 学習を止めるタイミングの判断：val loss の最小点・val IoU の最大点を狙う
- Early Stopping：val loss が改善しなくなったら自動で学習を止める考え方
- `best_deeplabv3plus_cable.pth` を保存している理由（最良の val IoU 時点の重みを残す）

### 第6章　学習の実践
- データセットと `Dataset` クラス（`__len__` / `__getitem__`）
- `DataLoader`：バッチ・シャッフル・ワーカー
- 順伝播（forward）と逆伝播（backward）の流れ
- `optimizer.zero_grad()` が必要な理由
- train / val 分割の意味

### 第7章　評価指標
- Accuracy がセグメンテーションに向かない理由（クラス不均衡）
- IoU（Intersection over Union）の計算式と直感
- `calc_iou_from_logits` のコードを読む
- Precision・Recall・F1 スコアとの関係

### 第8章　推論と後処理
- `model.eval()` と `torch.no_grad()` の意味
- ロジット → sigmoid → 閾値（0.5）でマスク生成する流れ
- 閾値を変えると何が変わるか（Precision と Recall のトレードオフ）
- リアルタイム推論（`infer_live.py`）の処理フロー

### 第9章　DeepLabV3+ のアーキテクチャ
- DeepLab シリーズの歴史（V1 → V3+）
- Atrous（ダイレーテッド）畳み込み：解像度を落とさずに受容野を広げる
- ASPP（Atrous Spatial Pyramid Pooling）：多スケールの特徴を捉える
- DeepLabV3+ 全体の構造（エンコーダ・ASPP・デコーダの流れ）
- `segmentation_models_pytorch` でのモデル定義コードとの対応
