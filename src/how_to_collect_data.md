# データ収集手順書

RealSense D405 でケーブルの画像を収集し、DeepLabV3+ の学習データを整える手順です。

---

## 撮影スクリプトの実行

`take_depth_rgb_image.py` を使って画像を撮影します。

**実行方法:**

```
cd src/mz07_demo_0624
python take_depth_rgb_iamge.py
```

カメラ映像がウィンドウに表示されます。

- **Space キー** を押すと BGR 画像と深度画像が `nkr_data/` に保存されます
- **ESC キー** で終了します

保存されるファイル:

```
src/mz07_demo_0624/nkr_data/
├── bgr_0000.png    ← BGR カラー画像
├── depth_0000.png  ← 深度画像（mm 単位）
├── bgr_0001.png
├── depth_0001.png
…
```

## データ収集時の注意（学習用）
> ここでは、データ収集とは写真撮影のことであると理解して良い。必ず指定した条件で撮影する必要があるのでスクリプトを実行することで写真撮影してほしい。
- **必ず**カメラはロボットハンドの先端に設置した状態で撮影を行う。本番環境と同じ視点でなければ学習が役に立たない。
- ケーブル形状、撮影位置、照明条件、他の物品の映り込み条件を様々に変形させながら,合計でも最低限 200 枚以上を撮影する。
- ロボットハンドの位置を変更し、毎回の撮影で背景を変化させて、写真を撮影する必要がある。5回に1回はロボットハンドを動かしてカメラの位置を変更してから写真撮影する必要がある。
- とにかくバリエーションの多さが大切なので、ケーブルの形は考えられるだけ多様な形に変化させて撮影する。位置を変化させて撮影してもよいが、2 回に 1 回はケーブル形状を曲げて変化させる必要がある。
- ケーブルの形状だけでなく照明条件も同時に変化させながら逐次写真撮影する。色の微妙な変化を学習させるのが目的なので、暗すぎてケーブルが見えないほど変化させてはいけない。可能であれば明るさや光の当たる角度を３，４パターンに変化させながら写真撮影を行う必要がある。
- 関係のないケーブルも必要に応じて写り込ませておく。他のケーブルと目的のケーブルの違いを学習させるのが目的である。
- 30 枚程度は目的のケーブルが写り込んでいないパターンで写真撮影する。ロボットハンドに取り付けたカメラの位置・照明条件を様々に変更してから撮影する。
- 30 枚程度は人の手が写り込んでいる状態の写真を用意する。ケーブルを遮るとしても、一部だけを遮るように撮影してほしい。この場合もロボットハンドに取り付けたカメラの位置・照明条件を様々に変更してから撮影する。
- 写真撮影スクリプトを実行する際は、ロボットは静止する必要がある。
